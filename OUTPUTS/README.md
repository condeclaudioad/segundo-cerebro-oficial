# OUTPUTS — entregables con fecha

Todo lo que tiene valor y se va a volver a mirar: análisis, decisiones, planes, guiones, auditorías, la matriz de la semana.

- Nombre: `AAAA-MM-DD-titulo-corto.md`. Si el entregable tiene varios archivos, una carpeta con ese mismo nombre.
- Cada output nuevo se enlaza desde [WIKI/index.md](../WIKI/index.md) (sección "Outputs recientes").
- Un output es una foto de ese día. Si después cambia algo, no se reescribe: se hace uno nuevo y el viejo queda como historia.
