# changelog — qué cambió y cuándo

Un archivo por mes: `changelog/2026-11.md`, `changelog/2026-12.md`…

**La entrada nueva va ARRIBA**, justo debajo del título del mes. Más nuevo primero, siempre. Nunca `cat >>`: eso manda la entrada al final, donde nadie la lee.

Formato de una entrada:

```markdown
## 3/11 — Procesé la llamada con el proveedor

Qué se hizo, en dos o tres líneas. Qué se decidió. Qué quedó pendiente.
Archivos: `WIKI/proveedores.md`, `OUTPUTS/2026-11-03-comparativa-proveedores.md`.
```

El changelog es lo primero que lee una sesión nueva (o una rutina) para saber dónde quedaste.
