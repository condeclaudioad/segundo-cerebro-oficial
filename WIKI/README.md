# WIKI — tu conocimiento ordenado

Esta carpeta es de la IA. **No la edites a mano**: si algo está mal, decíselo en el chat y ella lo corrige (y si la corrección vale para siempre, la guarda en `MEMORIA/`).

- Un archivo por tema: `negocio.md`, `clientes.md`, `ads.md`, `contenido.md`…
- Cada tema es autocontenido: lo abrís y entendés el estado actual sin leer nada más.
- [index.md](index.md) es el mapa. Corto. Una línea por tema.
- Los temas se conectan entre sí con `[[nombre-tema]]`.

Cuando instalás el cerebro (`/instalar`) nacen `yo.md` y `negocio.md`. Cuando mapeás tu negocio (`/mapear-negocio`) nace `mapa-de-procesos.md`. El resto crece solo con el uso.
